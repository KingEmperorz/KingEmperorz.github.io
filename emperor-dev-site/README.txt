YOUR DEVELOPMENT WEBSITE
========================

FILES
- index.html ............. Main studio / development portfolio homepage
- project-hudson.html .... Project Hudson branded project page
- styles.css ............. All design, responsive layout, animations, themes
- script.js .............. Site configuration + menu + animation behavior

HOW TO RENAME THE WEBSITE
1. Open script.js
2. Find:
   studioName: "YOUR STUDIO"
3. Replace YOUR STUDIO with your final website / studio name.

HOW TO OPEN IT
Double-click index.html.

HOW TO ADD SCREENSHOTS
The media areas are placeholders right now. Replace them later with image tags such as:
<img src="images/hoboken.png" alt="Hoboken development screenshot">

You can create an /images folder next to these files and place your images there.

HOW TO PUBLISH IT LATER
This site is fully static and can be published using GitHub Pages, Netlify, Vercel, Cloudflare Pages, or most normal web hosts.

PROJECT STRUCTURE
The studio homepage uses one neutral high-end development brand.
Project Hudson uses its own cyan rail/operations visual theme.
Future projects can get completely different colors, typography, layouts, and branding while staying under the same studio website.
